# Instruções do projeto

- Este repositório contém um único portfólio web Angular no workspace Nx. Consulte `package.json`, `project.json` e `nx.json` para confirmar scripts, versões e alvos disponíveis antes de orientar ou executar tarefas.
- Leia a skill aplicável em `.agent/skills/` antes de implementar uma mudança relevante. As skills `angular-developer`, `angular-cdk`, `portfolio-tests`, `portfolio-performance`, `portfolio-integrations`, `design-md`, `debugging-and-error-recovery`, `context-engineering` e `observability-and-instrumentation` são a referência deste projeto.
- Preserve a estrutura existente do app e prefira componentes, serviços, estilos e padrões já adotados. Não introduza frameworks, bibliotecas de ícones, sistemas de CSS ou dependências sem necessidade demonstrada.
- O portfólio é um site pessoal. Priorize conteúdo claro sobre apresentação profissional, projetos, competências e formas de contato. Não inclua regras de negócio, telas ou integrações herdadas de outros produtos.
- Use nomes de código em inglês e textos voltados ao visitante em português, salvo quando o conteúdo do portfólio pedir outro idioma.
- Não invente experiências, clientes, métricas, links ou qualificações pessoais. Reaproveite apenas informações já presentes no repositório ou fornecidas pelo usuário.
- Ao concluir mudanças de código, valide os alvos afetados definidos pelo próprio projeto e relate qualquer verificação que não pôde ser executada. Para mudanças só de documentação, confira os links e a formatação.
- Em qualquer banco de dados, somente consultas `SELECT` são permitidas. Não execute procedures, escritas, migrações, seeds nem aplicações ou testes que possam alterar dados.
